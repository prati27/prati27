## 🧠 How I'm Learning

Instead of following long video courses, I'm learning by **building one project progressively**.

For every concept:

```text
Understand
    ↓
Design
    ↓
Implement
    ↓
Test
    ↓
Break
    ↓
Debug
    ↓
Document
```

The goal isn't to collect technologies.

The goal is to understand:

* **Why** a technology exists
* **How** it works
* **When** to use it
* **What** happens when things fail
* **How** to design production-ready systems
